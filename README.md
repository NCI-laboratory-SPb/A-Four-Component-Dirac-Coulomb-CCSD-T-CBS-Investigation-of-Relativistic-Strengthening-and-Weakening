# A Four-Component Dirac-Coulomb CCSD(T)/CBS Investigation of Relativistic Strengthening and Weakening of Three-Center Four-Electron Interactions
The present repository provides the output files generated by four-component calculations, along with the custom scripts used in the manuscript «A Four-Component Dirac-Coulomb CCSD(T)/CBS Investigation of Relativistic Strengthening and Weakening of Three-Center Four-Electron Interactions ».
